# Contributing

This repository is primarily a public research notebook. Contributions that improve technical clarity, fix references, or add generally useful capsule-antenna methodology are welcome.

Please do not submit:

- copyrighted paper PDFs or figures without redistribution permission;
- private HFSS projects or unpublished collaborator data;
- patient or personally identifying medical data;
- proprietary measurement files whose release is not authorized.

For technical corrections, open an issue or propose a focused pull request with a clear source or derivation.
