## Problem framing

A single narrow resonance can be fragile in a capsule because tissue properties, geometry and location can detune the antenna. A broadband design provides more margin against these environmental changes.

## Publicly reported results

The official UESTC research feature reports the following maximum gains:

| Frequency | Maximum gain |
|---:|---:|
| **915 MHz** | **−24.0 dBi** |
| **1.43 GHz** | **−22.9 dBi** |
| **2.45 GHz** | **−19.3 dBi** |
| **2.45 GHz, fabricated test** | **−20.1 dBi** |

The same source describes good return-loss and gain behavior across the working band.

## Why a Minkowski-like geometry can broaden response

Repeated perturbations alter the current path at several geometric scales. In practice this can create nearby resonant contributions and modify the input-impedance trajectory, making it possible to obtain a wider matched region than a simple single-scale element.

## What to check beyond S11

A broadband \(|S_{11}|\) curve is valuable, but a robust design should also check:

- gain versus frequency;
- radiation efficiency;
- pattern stability;
- sensitivity to tissue properties;
- sensitivity to fabrication and bending;
- agreement between simulation and fabricated measurement.

The reported fabricated gain at 2.45 GHz is therefore particularly useful because it provides a bridge between simulation and physical realization.
